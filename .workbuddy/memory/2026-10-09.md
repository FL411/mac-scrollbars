## Mac Scrollbars 1.1.0 检查 + 部分网页滚动条失效修复（1.2.0）

- 全项目检查：MV3 合规、权限最小化、release/verify/zip 三方一致，1.1.0 可正常发布。
- 用户反馈部分网页滚动条无法替换，定位两个根因并修复，版本升至 1.2.0：
  1. **Chrome 121+ 标准属性冲突**：网站自行声明 `scrollbar-width`/`scrollbar-color` 时，`::-webkit-scrollbar-*` 伪元素样式被浏览器忽略（GitHub、YouTube 等已迁移此写法）。修复：content.css 注入 `html[data-mac-scrollbars="on"], html[data-mac-scrollbars="on"] * { scrollbar-width: auto !important; scrollbar-color: auto !important; }` 强制回初始值，使伪元素样式重新生效。
  2. **iframe 未注入**：manifest content_scripts 加 `all_frames: true`；popup.js `sendMessage` 加 `{ frameId: 0 }` 防止取到 iframe 域名。
- 新增 `test/scrollbar-test.html` 四区块验证页（标准属性容器/整页属性/iframe/Shadow DOM），Shadow DOM 为已知限制（样式隔离，纯 CSS 无法穿透）；file:// 页面需开"允许访问文件网址"。
- 打包坑：PowerShell 5.1 `Compress-Archive` 写入反斜杠路径不符合 zip 规范 → 改用 `C:\Windows\System32\tar.exe -a -cf`（bsdtar，正斜杠条目）。
- 发布物：`release/mac-scrollbars-1.2.0.zip`（10 文件，与源码 diff 一致），旧 1.1.0 zip 保留回滚用。verify/ 已同步。
