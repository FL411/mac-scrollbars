Mac Scrollbars 修复验证页

在扩展管理页“重新加载”扩展并刷新本页面后，逐项核对下方四个区块。

使用方法：本页是本地文件，需先在 edge://extensions / chrome://extensions 的扩展详情页开启“允许访问文件网址”，再重新加载扩展、刷新本页。 修复后所有可滚动区域都应出现细窄圆角的 mac 风格滚动条。

① 网站使用标准属性 本次修复

此容器声明了 scrollbar-width: thin; scrollbar-color: #d06060 #f0f0f0;——修复前扩展样式会被 Chrome 121+ 禁用，红色滚动条原样保留；修复后应变为 mac 风格。

向下滚动到最底部看看滚动条样式。

② 整页标准属性 本次修复

页面 <html> 上声明了 scrollbar-color: #d06060 #f0f0f0;，修复前最右侧的整页滚动条是红色的；修复后应变为 mac 风格细条。

拖动浏览器窗口最右侧的滚动条即可验证。

③ iframe 内部滚动 本次修复

修复前 content script 只注入顶层页面，iframe 内滚动条完全不受影响；开启 all_frames 后这里也应出现 mac 风格。

④ Shadow DOM 内部滚动 已知限制

Shadow DOM 内部受浏览器样式隔离保护，纯 CSS 方案无法覆盖，此处预期仍是浏览器原生样式——属于限制而非故障。
