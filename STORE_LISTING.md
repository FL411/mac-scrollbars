# Store Listing

## Name

Mac Scrollbars

## Short Description

Slim, rounded, macOS-inspired scrollbars for Chrome and Edge web pages.

## Detailed Description

Mac Scrollbars gives ordinary web pages a quieter, macOS-inspired scrollbar style.

Features:

- Slim rounded scrollbar thumb
- Always visible or show while scrolling
- Follow browser light and dark appearance
- Light and dark presets with custom colors
- Adjustable width and opacity
- One-click enable or disable for the current website

The extension has one purpose: changing scrollbar appearance on web pages. It does not collect page content, browsing history, or personal data. It does not use analytics or external servers.

## Permission Justification

The extension needs access to ordinary web pages only to apply the selected scrollbar CSS. The `storage` permission saves the user's appearance preferences.

## Privacy Disclosure

See `PRIVACY.md`. The extension does not collect or transmit personal data.
