Why restyle scrollbars?

Default scrollbars are loud. On Windows they take around seventeen pixels, draw a solid grey block on every page, and fight with carefully designed layouts. A slim rounded thumb reads as a hint instead of a headline.

This page exists only to demonstrate the difference between the native scrollbar and the style this extension applies. The text you are reading is filler; the scrollbar is the content.

What changes

The thumb becomes an eight-pixel rounded pill, floating over a transparent track. It darkens slightly on hover, and in "show while scrolling" mode it only appears while you actually scroll, then fades away.

Colors follow the browser theme, or can be forced light or dark with two custom colors. Width and opacity are adjustable, and any site can be excluded with one click.

How it works

The extension injects a small stylesheet into every frame of every ordinary web page. It styles the WebKit scrollbar pseudo elements and neutralizes the standard scrollbar properties that Chromium 121 and later use to disable them, so the custom look keeps working on sites that set those properties themselves.

No page content is read, nothing is transmitted, and preferences live in your browser account storage.

Try it

Load the extension, open any page, and scroll. The difference is easiest to see on long reading sessions, documentation sites, and code-heavy pages where a fat grey bar breaks the layout's rhythm.
